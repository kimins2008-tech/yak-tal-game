# 약탈게임

초등학생도 쉽게 사용할 수 있도록 밝고 단순한 화면으로 만든 실시간 멀티플레이 웹게임입니다.

## 인터넷에 공개 배포하기 (Render 예시)

이 프로젝트에는 `render.yaml` 배포 설정이 포함되어 있습니다.

1. GitHub 계정을 만들고 로그인합니다.
2. 새 저장소(repository)를 만듭니다.
3. 압축을 푼 이 프로젝트의 파일 5개(`package.json`, `server.js`, `render.yaml`, `README.md`, `public/index.html`)를 저장소에 올립니다.
4. Render에 가입하고 GitHub 계정을 연결합니다.
5. Render 대시보드에서 **New → Blueprint**를 선택하고 방금 만든 GitHub 저장소를 연결합니다.
6. `render.yaml` 설정을 확인하고 배포를 진행합니다.
7. 배포가 끝나면 `https://...onrender.com` 형태의 주소가 생깁니다. 이 주소를 선생님과 학생들이 함께 엽니다.
8. 선생님이 방을 만들면 5자리 코드가 나오고, 학생들은 같은 사이트에서 코드와 닉네임을 입력해 입장합니다.

Render 공식 안내:
- https://render.com/docs/your-first-deploy
- https://render.com/docs/websocket
- https://render.com/docs/free

### 무료 서비스 사용 시 참고
Render 무료 웹 서비스는 15분 동안 HTTP 요청이나 기존 WebSocket 메시지가 없으면 잠들 수 있으며, 다시 접속할 때 깨어나는 데 약 1분이 걸릴 수 있습니다. 무료 서비스는 재시작/잠자기/재배포 시 메모리에만 저장된 게임방이 사라질 수 있으므로, 수업 중 실제 운영에는 수업 전에 사이트를 열어 테스트하고 게임을 진행하는 것을 권장합니다. 안정적인 수업 운영이 필요하면 상시 실행되는 유료 인스턴스나 별도 저장소/재접속 복구 기능을 추가하는 편이 좋습니다.

## 로컬 실행 방법

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 열고 `npm install`을 실행합니다.
3. `npm start`를 실행합니다.
4. 브라우저에서 `http://localhost:3000`에 접속합니다.

## 게임 규칙 구현

- 방장 1명은 플레이어가 아니며 현황판만 봅니다.
- 플레이어 최대 6명, 시작 금괴 10개, 총 5라운드.
- 공격은 생존 플레이어 한 명을 지목합니다.
- 방어는 그 라운드의 공격을 모두 막으며 연속 사용 불가.
- 반사는 자신을 공격한 플레이어 각각에게서 금괴 1개씩 얻습니다. 아무도 공격하지 않으면 금괴 2개를 잃습니다.
- 더블은 게임 전체에서 1회 사용 가능하며 해당 라운드에 획득하는 금괴를 2배로 합니다. 상대가 잃는 양은 1개 그대로입니다.
- 금괴가 0개가 되면 즉시 탈락합니다.
- 라운드 선택 제한은 3분이며 30초 이하에서 강조 표시합니다.
- 생존 플레이어 모두 선택하면 즉시 판정합니다. 시간 초과 미선택은 무행동입니다.

## 판정 메모

한 라운드의 공격/반사 결과는 같은 시점의 선택을 기준으로 계산하고, 변화량을 모아 동시에 적용합니다. 따라서 한 라운드 중간에 금괴를 얻거나 잃었다는 이유로 다른 플레이어의 선택이 취소되지는 않습니다.

현재 버전은 프로토타입입니다. 인터넷 공개 전에는 재접속 복구, 방장 연결 종료 처리, 서버 저장소, 악용 방지 등을 추가하는 것을 권장합니다.
